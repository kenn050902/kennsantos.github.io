# Technical capabilities image assets

The portfolio's Technical Capabilities cards use the PNG files in this folder. To update a skill image, replace its PNG while keeping the filename, or change the matching `src` in the capabilities section of `index.html`.

The PNGs are 96 × 96 pixels. Source SVGs are kept alongside them where available.

## Artwork sources

- Power BI, Salesforce, SAP, and Python marks: [Vector Logo Zone](https://www.vectorlogo.zone/)
- SQL Server mark: [Devicon](https://github.com/devicons/devicon)
- OpenAI mark: [Tabler Icons](https://github.com/tabler/tabler-icons)
- Power Query, Excel, Power Automate, Power Apps, SharePoint, and Tableau: simplified local visual marks drawn for this portfolio; they are not official brand artwork.

All product names remain in the adjacent headings, so the images are decorative. Replace the simplified marks with approved official artwork if you prefer exact product logos.
