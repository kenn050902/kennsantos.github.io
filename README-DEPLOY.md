# Kenn Santos portfolio redesign

This is a replacement `index.html` for the existing GitHub Pages portfolio.

## What changed
- Premium dark-navy consulting style with restrained teal and gold accents.
- Stronger client-focused positioning and clearer service descriptions.
- Responsive navigation, mobile layouts, keyboard focus states, skip link, and reduced-motion support.
- Case studies describe the purpose and analysis without inventing ROI or client outcomes.
- Removes unsupported "available now" language and frames availability as select freelance projects.
- Removes the public phone number from the footer to keep project inquiries on a professional email channel.
- Removes fixed public pricing so the scope can be assessed before quoting.
- Keeps existing project preview images, resume PDF, favicon, canonical URL, and social metadata paths.

## Install
1. Download and unzip this package.
2. Open the `index.html` in a browser to preview.
3. In your repository, replace the existing root `index.html` with this file.
4. Keep the existing `assets/` folder unchanged; the new page references the current asset paths.
5. Commit and push to the repository's publishing branch (`main` in the current repository setup).
6. Wait for GitHub Pages to finish publishing, then test desktop and mobile.

## Important review before publishing
- Confirm role titles, dates, technologies, and descriptions are accurate.
- The project previews are described as portfolio examples; ensure the images and any data shown are safe to publish.
- If you want to advertise a firm response time, pricing, or specific availability, add only what you can reliably honor.
- Run a browser check and Lighthouse/accessibility review after deployment.
