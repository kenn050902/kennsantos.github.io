## Overview

The site is designed to help prospective employers and freelance clients understand Kenn's reporting experience, technical capabilities, and the types of analytics projects he can support.

- **Services:** Power BI dashboard development, reporting improvement, data preparation and SQL, and workflow automation.
- **Selected work:** HR analytics, payroll operations, and sales performance dashboard examples.

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a modern browser.

For a more realistic local test, run a simple static server from the repository directory, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Replace the root `index.html` with the updated file.
2. Keep the referenced `assets/` directory in place.
3. Commit and push the changes to the repository's publishing branch.
4. In GitHub, check **Settings → Pages** to confirm the publishing source.
5. Wait for the deployment to finish, then test the live website on desktop and mobile.

## Before publishing changes

- Verify job titles, dates, skills, and project descriptions.
- Confirm all project screenshots and sample data are approved for public display.
- Do not publish confidential employer/client data or private dashboard links.
- Describe demonstration projects as examples; do not imply that sample data represents verified client outcomes.
- Check the email link, LinkedIn link, resume PDF, project images, navigation, and mobile menu.
- Test keyboard navigation and review the page with browser accessibility tools.
- Confirm the canonical URL and social preview image still point to the intended live site.

## Content and credibility notes

The portfolio intentionally avoids unverified performance metrics, fabricated testimonials, and guaranteed business outcomes. Add quantified results only when they can be supported and shared publicly.

Service scope, timelines, and pricing should be agreed with each client after clarifying data sources, requirements, access, and deliverables.
