Power BI

  • Build interactive dashboards and KPI scorecards.
  • Create DAX measures, calculated columns, and time-based metrics.
  • Design relationships and reporting data models.
  • Transform data with Power Query.
  • Configure drill-through, slicers, filters, and report navigation.
  • Troubleshoot refreshes and optimize report performance.

Salesforce

CRM data & reporting
  • Work with Salesforce data exports for analysis.
  • Prepare and clean CRM datasets for reporting.
  • Connect Salesforce data to Power BI through available connectors or exports.
  • Build sales, pipeline, customer, and activity dashboards.
  • Combine CRM data with operational and finance datasets.
  • Track trends and performance against business KPIs.

SQL

Data querying & preparation
  • Write SELECT queries and filter reporting datasets.
  • Join tables and combine multiple data sources.
  • Use GROUP BY, aggregations, CASE, and subqueries.
  • Build CTE-based queries for clearer logic.
  • Validate records and investigate data discrepancies.
  • Prepare structured datasets for dashboards.

Power Query

Data transformation
  • Clean, reshape, and combine Excel and CSV files.
  • Append monthly or recurring data extracts.
  • Change data types and standardize columns.
  • Build reusable transformation steps.
  • Handle nulls, duplicates, and inconsistent values.
  • Prepare data models for Power BI reporting.

Microsoft Excel

Analysis & reconciliation
  • Use XLOOKUP, VLOOKUP, INDEX/MATCH, and conditional formulas.
  • Create PivotTables and summary reports.
  • Clean, validate, and reconcile data.
  • Build recurring reporting templates.
  • Analyze operational and performance data.

Power Automate

Workflow automation
  • Create scheduled and automated cloud flows.

  • Build approval and exception-handling workflows.
  • Move data between supported Microsoft 365 services.

Power Apps

  • Connect apps to SharePoint lists.

SharePoint

SAP Analytics Cloud

Enterprise analytics

Tableau
